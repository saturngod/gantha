# Gantha - Ebook Builder

Gantha is a tool to build static ebook websites from markdown files, optimized for Myanmar content.

## Usage

1. Define your book structure in `toc.json`. You can use `bun update-toc.js` that will generate toc base on md files.
2. Run `bun run build`.
3. The output will be in the `build/` directory.

## Plugin System

Gantha supports a plugin system to extend functionality. You can add plugins to process markdown content, manipulate HTML output, or hook into the build lifecycle.

### Using Plugins

To use a plugin, add it to the `plugins` array in your `toc.json` file. You can use both NPM packages and local files.

```json
{
  "title": "My Book",
  "chapters": [...],
  "plugins": [
    "gantha-pdf", // NPM package
    "./plugins/my-local-plugin.ts" // Local file (relative to project root)
  ]
}
```

#### 1. NPM Package
Install the plugin via your package manager (e.g., `bun add gantha-pdf`) and add its name to `toc.json`.

#### 2. Local Plugin
Create a plugin file (e.g., `plugins/my-plugin.ts`) and add its relative path to `toc.json`.

### Developing Plugins

Plugins should export an `init` function that receives a `PluginContext`. We recommend writing plugins in TypeScript.

**Example Plugin (`my-plugin.ts`):**

```typescript
import type { PluginContext } from './types'; // Import types from Gantha

export default {
    init: (context: PluginContext) => {
        console.log('🔌 My Plugin Initialized');

        // Hook: beforeBuild - Runs before the build process starts
        context.on('beforeBuild', () => {
            console.log('Build starting...');
        });

        // Hook: processMarkdown - Transform markdown content
        context.on('processMarkdown', (md: string) => {
            // Example: Add a signature to every chapter
            return md + '\n\n_Generated by Gantha_';
        });

        // Hook: processHTML - Transform generated HTML
        context.on('processHTML', (html: string) => {
            // Example: Inject a script tag
            return html.replace('</body>', '<script src="analytics.js"></script></body>');
        });

        // Hook: afterBuild - Runs after the build is complete
        context.on('afterBuild', () => {
            console.log('Build finished!');
        });
    }
};
```

### Available Hooks

- `beforeBuild`: Executed before any build steps.
- `processMarkdown`: Transform raw markdown content. Receives string, returns string (or Promise<string>).
- `processHTML`: Transform generated HTML content. Receives string, returns string (or Promise<string>).
- `afterBuild`: Executed after all files are generated.
