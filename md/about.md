# About

Gantha is a static site generator that transforms Markdown files into beautiful, book-like websites. The name "Gantha" (ဂန္ထ) means "book" or "treatise" in Myanmar language, reflecting its core purpose of creating digital books and documentation with an elegant, readable design.

## What is Gantha?

Gantha is "Just Another Markdown to Website" builder, but with a specific focus on creating book-style layouts. Unlike generic static site generators, Gantha is designed specifically for:

- **Long-form content** - Perfect for books, documentation, and educational materials
- **Myanmar language support** - Built with Myanmar content creators in mind
- **Clean typography** - Emphasis on readability and beautiful text presentation
- **Simple workflow** - From Markdown to website in minutes

## Technology Stack

Gantha is built with modern web technologies:

- **TypeScript** - For type-safe, maintainable code
- **Bun** - Fast JavaScript runtime for quick builds
- **Marked** - Reliable Markdown parsing
- **Clean CSS & Terser** - Optimized asset minification

## Design Philosophy

Gantha follows these core principles:

1. **Simplicity First** - Easy to use, minimal configuration required
2. **Content-Focused** - Clean layouts that let your content shine
3. **Performance** - Fast builds and lightweight output
4. **Accessibility** - Readable typography and semantic HTML
5. **Localization** - Special attention to Myanmar language rendering

## Use Cases

Gantha is ideal for:

- **Digital books** - Convert your manuscripts to interactive websites
- **Documentation** - Create beautiful docs for your projects
- **Educational content** - Build course materials and tutorials
- **Personal blogs** - Especially for long-form writing
- **Myanmar content** - Optimized for Myanmar language typography

Whether you're writing a technical manual, a novel, or educational content in Myanmar, Gantha provides the tools to create a professional, book-like reading experience on the web.
